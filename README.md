Launch Ledger ranks protocols that record no token in the sealed DefiLlama snapshot. The browser refits the same cap and token-record models that write the board and checks every row against `board.json`. Leave-one-out and listing-cohort tests show how the models compare with their baselines. Costed farm routes report FARM, MARGINAL or SKIP against fees and a 4% T-bill scenario, with adjustable deposit, drop share and horizon.

With Node 22.18 or later, run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json` and open `out/dashboard/index.html` in Chrome.
